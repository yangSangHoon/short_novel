# 종이결 — 짧은 소설 플랫폼

한 페이지에 한 장면. 쓰는 대로 삽화가 따라 그려지고, 독자는 그림책처럼 넘기며 읽습니다. 모바일을 먼저 보고 만들었습니다.

- **쓰기 좋은 에디터** — 장(page) 단위로 쓰는 원고지. 자동 저장, 집중 모드, 장 목록, 긴 글 자동 분할.
- **자동 삽화** — 본문을 읽어 장소·시간·날씨·분위기·인물·소품을 추려내고 SVG 한 컷을 그립니다. 외부 API 없이 브라우저 안에서 끝납니다.
- **그림책형 뷰어** — 표지 → 그림+글 한 칸씩 → 끝. 다음 버튼, 화면 좌우 탭, 키보드(←/→/space), 스와이프. 세로로 쭉 내리는 이어보기 모드도 있습니다.

## 디자인

Claude Design 프로젝트 *웹소설 플랫폼*(classical 디자인 시스템)을 옮긴 것입니다.
390×800 모바일 프레임으로 그려진 세 장의 아트보드 — 작품 홈 · 독자 뷰어 · 작가 에디터 — 를
그대로 화면 셋에 대응시켰습니다.

- 종이 바탕(`#f5f1ec`)에 결 노이즈를 얕게 깔고, 그 위에 인화지처럼 테두리를 두른 삽화(`.plate`)를 얹습니다.
- 고운바탕(본문) · 고운돋움(UI) · Cormorant Garamond(숫자·로마자) 세 벌을 씁니다.
- 금색 `#c8a24a` 은 회차·진행 표시, 장미색 `#f8dcdc`/`#a4545d` 은 주 행동, 풀색은 저장·메모에 씁니다.
- 삽화도 같은 결입니다. 검은 실루엣 대신 파스텔 색면과 부드러운 그림자를 쓰고, 밤도 검게 떨어뜨리지 않고 연보라로 둡니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 타입 검사 + 번들
npm run lint
```

원고는 브라우저 `localStorage` 에만 저장됩니다. 서버도 계정도 없습니다.

## 배포

기본 브랜치에 밀면 `.github/workflows/pages.yml` 이 빌드해서 GitHub Pages 에 올립니다.
→ https://yangsanghoon.github.io/short_novel/

저장소 이름 아래(`/short_novel/`)에 올라가므로 빌드 시 `GITHUB_REPOSITORY` 에서 base 경로를
끌어오고, 라우터도 같은 값을 basename 으로 씁니다. 로컬 빌드는 값이 없어 루트가 됩니다.
Pages 는 없는 경로에 `404.html` 을 내려주므로 워크플로가 `index.html` 을 그리로 복사해
`/read/…` 로 바로 들어오거나 새로고침해도 라우팅이 살아 있게 합니다.

## 자동 삽화가 동작하는 방식

`src/illustration/` 안에서 세 단계로 나뉩니다.

| 파일 | 역할 |
| --- | --- |
| `lexicon.ts` | 장소·시간·날씨·분위기·소품을 가리키는 한국어/영어 키워드 사전 |
| `analyze.ts` | 본문 → `SceneSpec`. 키워드 점수를 매겨 이기는 항목을 고르고, 대사와 인물 명사로 등장 인물 수를 추정합니다 |
| `palette.ts` | 시간대별 기본 색 + 분위기 틴트 |
| `places.tsx` | 장소별 배경(원경/중경/근경). 실내는 벽으로 하늘을 가리고 창문만 뚫습니다 |
| `Illustration.tsx` | 하늘·날씨·인물 실루엣·소품을 쌓아 한 장의 SVG로 합성 |

형태소 분석기는 쓰지 않습니다. 한국어는 조사가 붙어 늘어나므로 어간을 부분 문자열로 찾되,
한 글자짜리 키워드("비", "눈", "산")는 조사나 공백이 뒤따를 때만 인정해 `비밀`·`눈치` 같은 오탐을 막습니다.

그림은 **결정론적**입니다. 같은 글 + 같은 시드 = 언제나 같은 그림. 시드는 본문 해시와
페이지의 `seed` 값을 섞어 만들고, 작가가 "다시 그리기"를 누르면 `seed` 가 1 올라가 구도만 바뀝니다.

자동 추론이 마음에 들지 않으면 에디터 오른쪽 패널에서 항목별로 직접 고를 수 있습니다.
고르지 않은 항목은 계속 본문을 따라갑니다 (`page.sceneOverride`).

## 구조

```
src/
├─ illustration/   자동 삽화 엔진
├─ routes/         Library(서재) · Editor(쓰기) · Reader(읽기)
├─ components/     Button · Icon · TopBar · SceneControls
├─ lib/            localStorage 저장소, 원고 상태, 테마, 텍스트 유틸
└─ styles/         tokens.css(디자인 토큰) · global.css
```

색·타이포·간격은 모두 `src/styles/tokens.css` 의 CSS 변수 한 곳에서 나옵니다.
다른 디자인 시스템을 얹으려면 이 파일의 값만 갈아 끼우면 됩니다. 라이트/다크 두 벌이 있습니다.

## 모바일

- 모든 화면이 390px 폭을 기준으로 짜여 있고, 넓은 화면에서는 같은 단을 가운데에 둡니다.
- 하단 고정 조작부는 `env(safe-area-inset-bottom)` 을 반영합니다.
- 입력창 글자는 16px 이상이라 iOS 에서 초점이 가도 화면이 확대되지 않습니다.
- 손가락에는 hover 가 없으므로 `@media (hover: none)` 에서 숨은 도구를 항상 보여 줍니다.
- 뷰어는 좌우 스와이프와 화면 양쪽 탭으로 넘깁니다. 컷 띠는 가로 스크롤 + 스냅입니다.

## 키보드

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 에디터 | `⌘/Ctrl + Enter` | 다음 장 만들기 |
| 에디터 | `⌘/Ctrl + ←` `→` | 장 이동 |
| 에디터 | `Esc` | 집중 모드 해제 |
| 뷰어 | `→` `Space` `Enter` | 다음 칸 |
| 뷰어 | `←` | 이전 칸 |
