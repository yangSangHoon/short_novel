# 한 장 — 짧은 소설 플랫폼

한 페이지에 한 장면. 쓰는 대로 삽화가 따라 그려지고, 독자는 웹툰처럼 넘기며 읽습니다.

- **쓰기 좋은 에디터** — 장(page) 단위로 쓰는 원고지. 자동 저장, 집중 모드, 장 목록, 긴 글 자동 분할.
- **자동 삽화** — 본문을 읽어 장소·시간·날씨·분위기·인물·소품을 추려내고 SVG 한 컷을 그립니다. 외부 API 없이 브라우저 안에서 끝납니다.
- **웹툰형 뷰어** — 표지 → 그림+글 한 칸씩 → 끝. 다음 버튼, 화면 좌우 탭, 키보드(←/→/space), 스와이프. 세로로 쭉 내리는 이어보기 모드도 있습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 타입 검사 + 번들
npm run lint
```

원고는 브라우저 `localStorage` 에만 저장됩니다. 서버도 계정도 없습니다.

## 자동 삽화가 동작하는 방식

`src/illustration/` 안에서 세 단계로 나뉩니다.

| 파일 | 역할 |
| --- | --- |
| `lexicon.ts` | 장소·시간·날씨·분위기·소품을 가리키는 한국어/영어 키워드 사전 |
| `analyze.ts` | 본문 → `SceneSpec`. 키워드 점수를 매겨 이기는 항목을 고르고, 대사와 인물 명사로 등장 인물 수를 추정합니다 |
| `palette.ts` | 시간대별 기본 색 + 분위기 틴트 |
| `places.tsx` | 장소별 배경(원경/중경/근경). 실내는 벽으로 하늘을 가리고 창문만 뚫습니다 |
| `Illustration.tsx` | 하늘·날씨·인물 실루엣·소품을 쌓아 한 장의 SVG로 합성 |

형태소 분석기는 쓰지 않습니다. 한국어는 조사가 붙어 늘어나므로 어간을 부분 문자열로 찾되,
한 글자짜리 키워드("비", "눈", "산")는 조사나 공백이 뒤따를 때만 인정해 `비밀`·`눈치` 같은 오탐을 막습니다.

그림은 **결정론적**입니다. 같은 글 + 같은 시드 = 언제나 같은 그림. 시드는 본문 해시와
페이지의 `seed` 값을 섞어 만들고, 작가가 "다시 그리기"를 누르면 `seed` 가 1 올라가 구도만 바뀝니다.

자동 추론이 마음에 들지 않으면 에디터 오른쪽 패널에서 항목별로 직접 고를 수 있습니다.
고르지 않은 항목은 계속 본문을 따라갑니다 (`page.sceneOverride`).

## 구조

```
src/
├─ illustration/   자동 삽화 엔진
├─ routes/         Library(서재) · Editor(쓰기) · Reader(읽기)
├─ components/     Button · Icon · TopBar · SceneControls
├─ lib/            localStorage 저장소, 원고 상태, 테마, 텍스트 유틸
└─ styles/         tokens.css(디자인 토큰) · global.css
```

색·타이포·간격은 모두 `src/styles/tokens.css` 의 CSS 변수 한 곳에서 나옵니다.
다른 디자인 시스템을 얹으려면 이 파일의 값만 갈아 끼우면 됩니다. 라이트/다크 두 벌이 있습니다.

## 키보드

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 에디터 | `⌘/Ctrl + Enter` | 다음 장 만들기 |
| 에디터 | `⌘/Ctrl + ←` `→` | 장 이동 |
| 에디터 | `Esc` | 집중 모드 해제 |
| 뷰어 | `→` `Space` `Enter` | 다음 칸 |
| 뷰어 | `←` | 이전 칸 |
